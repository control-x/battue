Fiche de préparation

Disparition ? Appelez d'abord le 17 ou le 112

La battue est créée avec cette fiche ; vous vérifiez le dernier lieu connu avant de la lancer. Les informations pour les secours restent dans la fiche.

Préparez-la au calme. Le jour où votre proche disparaît, un seul geste lance la battue pré-remplie, avec ses lieux du passé marqués sur la carte.

Chiffrée sur votre téléphone : seules les personnes qui ont le lien peuvent la lire, pas même Battue. Si le lien est perdu, la fiche est perdue.

    Le lien de la fiche

    Ce lien est la seule clé. Envoyez-le aux proches qui pourraient lancer la battue, et imprimez la fiche-clé pour la ranger avec les papiers importants. Battue ne peut pas le retrouver.

    Sans ouverture pendant 3 ans, la fiche s'efface d'elle-même. Confidentialité · Mentions légales

    Fiche Battue

    En cas de disparition :

    1. Appelez le 17 ou le 112.
    2. Scannez ce code avec un téléphone.
    3. Touchez « Lancer une battue maintenant ».

    Ce code ouvre la fiche de préparation. Rangez cette page avec les papiers importants ; ne l'affichez pas.
